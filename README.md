# ACM-MM-2026 Dataset Track Submission

## ObsDriveBench: Benchmarking Multimodal Understanding under Adverse Weather with Observability Awareness

This repository contains the supplementary materials for Submission ID 149 to the ACM MM 2026 Dataset Track.

## 📦 Contents

1. **Supplementary Material**  
   `ACM2026_Submission_149_appendix.pdf` provides additional details of ObsDriveBench, including dataset statistics, data construction pipeline, prompt templates, and qualitative examples.

2. **Raw Data Examples**  
   `Dataset/raw_data/25/` contains sample multi-modal data, including CAM, LiDAR BEV, and RADAR BEV images.

3. **Evaluation Annotations**  
   `Eval/` includes annotation files for three capability dimensions:
   - Observability Awareness  
   - Spatial Reliability  
   - Risk-aware Decision Making  

4. **Training Data**  
   `Train/` contains training data used for supervised fine-tuning (SFT) and reinforcement learning (RL).

## 🚀 Release
